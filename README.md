# LD_Bootcamp

Lightning Developer Bootcamp Platform.

## 📖 Overview

The Lightning Developer Bootcamp (LD Bootcamp) is a hands-on learning platform designed to help developers build practical skills in Bitcoin, the Lightning Network, and modern blockchain development.

The bootcamp combines structured learning, coding exercises, and real-world projects to provide participants with the knowledge required to develop decentralized and Lightning-powered applications.

---

## 🚀 Features

- Interactive learning modules
- Practical coding exercises
- Bitcoin and Lightning Network development
- Hands-on projects
- Developer-friendly learning resources
- Open-source collaboration

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/MokasimUmer/LD_Bootcamp.git
```

### Navigate into the project

```bash
cd LD_Bootcamp
```

### Install dependencies

```bash
npm install
```

### Run the project

```bash
npm start
```
